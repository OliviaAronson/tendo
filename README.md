# Tendo

Mobile-first climbing, strength and recovery journal. Five-week training targets, required RPE on sessions, daily check-ins, recovery entries, personal records, and JSON/CSV export.

## Use

Hosted with GitHub Pages at https://oliviaaronson.github.io/tendo/ once Pages is enabled for the main branch root.

For local use, run `python3 -m http.server 8000` in this folder and open http://localhost:8000/.

## Data and privacy

Data is stored locally in the browser under the existing `tendo_v1` key for compatibility with earlier Tendo builds. No account or automatic sync exists. Use Settings → Export JSON backup regularly. A different device or browser starts with its own local data.

## Notes

This is a simplified release; detailed per-boulder logging, workout templates, and symptom before/after tracking from the earlier prototype are not yet available in this interface. Preserve backups before changing versions.
